Technische informatie

Redundantie = percentage van de codewoorden dat foutcorrectiedata is (geen gebruikersdata). Codewoord-capaciteit is de ruwe databytes-capaciteit voor deze versie/ECC-combinatie (incl. ~1-2 bytes overhead voor mode-/lengte-indicator, die niet in "databytes gebruikt" is meegeteld). De encoderingsmodus is een schatting op basis van de inhoud, niet uitgelezen uit de originele encoder.

Alles wordt lokaal in je browser gescand — er wordt niets geüpload naar een server.
